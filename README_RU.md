# Alatau City — цифровой двойник: полный пакет

Собрано 7 октября 2026 года. В архиве три способа запуска одного и того же города: готовая программа, страница для
браузера и проект Unity. Все данные о стройке, сетях, транспорте и деньгах смоделированы; это демо-сценарий,
не официальные данные.

Исходные документы проекта лежат рядом и не менялись: `context.md` (что это и как устроено), `startup.md`
(как открыть и собрать), `docs/`. Этот файл описывает только то, что добавлено к ним.

## 1. Что в архиве

| Папка или файл | Что это | Что нужно для запуска |
|---|---|---|
| `Build_Windows/AlatauCity.exe` | Двойник как программа: шесть модулей с аналитикой, кино-вид города | Windows 10/11 x64, видеокарта с DirectX 11/12. Unity не нужен |
| `web/AlatauCity_Film_3D.html` | Тот же город одной страницей: кино-вид, аналитика, ярлыки с паспортами, площадка моста | Браузер Edge или Chrome с WebGL 2. Ни сервер, ни интернет не нужны |
| `UnityProject/` | Проект Unity со всеми моделями, текстурами, скриптами и данными | Unity **6000.0.84f1**, см. раздел 4 |
| `web/` (остальное) | Исходники страницы и сборка | Только если страницу нужно пересобрать, см. раздел 5 |

Размер архива — около 410 МБ, после распаковки — около 2,1 ГБ. Распаковывайте в короткий путь, например `C:\Work\AlatauCity_DigitalTwin`.

## 2. Программа (без Unity)

1. Откройте `Build_Windows` и запустите `AlatauCity.exe`. Папку не разбирайте: рядом с exe должны лежать
   `AlatauCity_Data`, `MonoBleedingEdge`, `D3D12`, `UnityPlayer.dll`.
2. Если Windows предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
3. Выход — Alt+F4. Управление описано в `startup.md`, раздел 3.

Аналитика — в левой колонке иконок: Обзор, Стройка, Прогноз, Инфраструктура, Ситуационный центр, ИИ-управление.
Кино-вид (фасады, кровли, дороги, деревья, небо) работает во вкладке «Обзор»: **F6** включает и выключает его,
**F7 / F8** меняют время суток. В остальных вкладках город показан прежними ровными цветами, чтобы читались данные.

Сборка сделана из этого же проекта и весит около 1,1 ГБ (в `startup.md` указаны прежние 690 МБ).

## 3. Страница для браузера

Дважды щёлкните `web/AlatauCity_Film_3D.html`. Страница весит 19,9 МБ и содержит всё внутри себя.

- **Управление:** левая кнопка — сдвиг, правая — поворот, колесо — масштаб; клавиши W A S D, Q E, R F.
- **Верхняя панель:** сценарий застройки (четыре), «Ярлыки», «Аналитика», качество, язык (RU / EN).
- **Нижняя панель:** год 2025–2050, «Рост города», время суток, готовые виды.
- **Аналитика:** вкладки «Обзор», «Стройка», «Прогноз» считаются в браузере по тем же данным и формулам, что и в
  программе. Во вкладке «Прогноз» здания окрашиваются по результату.
- **Ярлыки:** объекты сетей, станции ЛРТ, районы, высотные доминанты. Клик — камера подлетает и открывается паспорт
  объекта. Клик по любому зданию открывает паспорт здания.
- **Площадка:** стройка моста в Golden District с аннотациями на земле, описанием проблемы на опоре №3 и
  предложением ИИ. Это учебный сценарий: проблема, показания и ответ ИИ заданы заранее, не рассчитаны.

В странице нет модулей «Инфраструктура», «Ситуационный центр» и «ИИ-управление», квартала BIM Gate Q1 и слоя
загрузки дорог; они есть в программе.

## 4. Проект Unity

1. Установите Unity **6000.0.84f1** через Unity Hub (Installs → Install Editor → Archive). Нужна именно эта версия.
2. Unity Hub → Projects → Add → Add project from disk → папка `UnityProject`.
3. Первый запуск занимает 10–20 минут: Unity создаёт папку `Library` и сжимает карту. Прерывать не нужно.
4. Откройте сцену `Assets/Scenes/AlatauCity.unity` и нажмите Play (окно Game: Full HD, Play Maximized).

Папка `Assets/Generated` с мешами города (около 800 МБ) уже в архиве, поэтому пересборка сцены не нужна.
Если город пустой, выполните меню **Alatau City → Rebuild Scene**. Остальное — в `startup.md`.

## 5. Пересобрать страницу (не обязательно)

Нужны Blender 5.x (используется как Python с чтением картинок, ничего не рендерит) и bash (на Windows — Git Bash).

```
bash web/build.sh notest
```

Сборка читает модели, карты, текстуры и данные из `UnityProject/Assets` и пишет `web/AlatauCity_Film_3D.html`.
Если Blender стоит не в стандартной папке: `BLENDER="путь/к/blender.exe" bash web/build.sh notest`.
Проверка в браузере (`bash web/build.sh` без `notest`, `web/test_objects.py`) требует Python с пакетом playwright и
Edge; пути задаются переменными `PY` и `PYLIBS`, подробности — в начале `build.sh`.

| Файл в `web/` | Назначение |
|---|---|
| `page.html`, `app.js`, `glsl_film.js`, `glsl_parts.js` | Оболочка страницы, 3D-сцена, шейдеры кино-вида |
| `analytics.js`, `analytics_text.js` | Вкладки «Обзор», «Стройка», «Прогноз», сценарии |
| `objects.js`, `objects_text.js`, `site.js` | Ярлыки, паспорта объектов, выбор здания, реки; площадка моста |
| `build_web.py`, `build.sh`, `lib/three.min.js` | Сборка одной страницы; three.js r128 (лицензия MIT) |
| `test_page.py`, `test_objects.py` | Проверки в браузере со снимками |

## 6. Что проверено и что нет

- Программа из распакованного архива запущена на ПК, где собирался пакет: здания и данные двойника загрузились
  без ошибок. Та же сборка перед упаковкой открыта в окне: интерфейс с аналитикой и город отображаются.
- Страница пересобрана из распакованного архива и совпала с вложенной байт в байт.
- Страница проверена в Edge на том же ПК (NVIDIA RTX 5060 Ti): без ошибок, около 60 кадров в секунду.
- На другом компьютере, на встроенной графике, в Chrome и Firefox не проверялось ничего.
- Открытие проекта Unity на другом компьютере не проверялось; состав папок тот же, что у штатного экспорта
  проекта (меню Alatau City → Export ZIP for team).

## 7. Чего в архиве нет

- Папки `Library` проекта Unity: она создаётся при первом открытии.
- Исходного файла `Alatau_City_3D.blend` набора QTwin: он нужен только для повторного экспорта геометрии.
- Снимков и фильмов кино-вида: они не нужны для запуска.
