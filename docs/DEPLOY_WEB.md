# Alatau City — как вывести двойник на домен (план)

Цель: двойник открывается по ссылке на нашем домене и выглядит так же, как в Unity у автора.

## Варианты

| | A. Стриминг (рекомендуем) | B. WebGL |
|---|---|---|
| Как работает | Наша Windows-сборка крутится на сервере с видеокартой; в браузер идёт видео (WebRTC), мышь и клавиатура — обратно | Браузер скачивает приложение и рисует на видеокарте посетителя |
| Картинка | 1:1 как у автора (та же сборка, та же видеокарта) | Зависит от компьютера посетителя; телефоны почти не потянут |
| Что открывает | Любой браузер, в т. ч. телефон и планшет | Только мощный ноутбук/ПК, Chrome/Edge |
| Загрузка | Секунды (видео) | Сотни МБ: меши города ~830 МБ, карты 8K, массивы фото-текстур |
| Доработка проекта | Почти ничего (для своего сервера — мост ввода, см. ниже) | Недели: память вкладки 2–4 ГБ, нет потоков, чтение `StreamingAssets` через `UnityWebRequest`, облегчение мешей и текстур, отказ от коллайдеров зданий |
| Стоимость | Видеокарта на каждого одновременного зрителя (облако — оплата по часам, или свой ПК с RTX) | Только хостинг статики |

**Рекомендация:** для презентаций инвесторам — **A, стриминг**. Позже, для массового публичного доступа, — облегчённая WebGL-версия (B) как отдельный продукт.

## Вариант A по шагам

### A1. Управляемый сервис (быстро, 1–2 дня)
Сервисы стриминга Unity/Unreal-приложений в браузер (например, Vagon Streams, PureWeb — сравнить цены и регион серверов):
1. `Alatau City → Build Windows` (или команда `BuildWindowsCI`, см. README) → zip `Builds/Windows`.
2. Загрузить zip в сервис, выбрать GPU-машину и разрешение 1920×1080.
3. Получить ссылку или iframe и встроить на страницу домена (`/alatau`).
4. Ограничить доступ (пароль или ссылка с токеном) и задать число одновременных сессий.

### A2. Свой сервер (дешевле при постоянной нагрузке, ~1 неделя)
- GPU-сервер Windows (облако или свой ПК с RTX), сборка запускается как служба.
- **Unity Render Streaming** (пакет `com.unity.renderstreaming`): компонент на камере, сигнальный веб-сервер (Node.js из пакета), TURN-сервер (coturn) для пользователей за NAT.
- Домен: nginx + TLS (Let's Encrypt) → страница `/alatau` и прокси к сигнальному серверу (`wss://…/signaling`).
- Доработка проекта: ввод сейчас идёт через старый `Input` (`Input.GetKey`, мышь), а Render Streaming передаёт ввод через Input System. Нужен мост ввода или переход на Input System (`Active Input Handling: Both`).

## Что уже готово (основа)
- Проект открывается одинаково на любой машине: `Assets/Editor/AlatauProjectSetup.cs` сам собирает город, открывает сцену, ставит Ultra и Full HD.
- Стабильные id файлов `Assets/Generated`: сцена из git работает у всех.
- Сборка без интерфейса для сервера сборки:
  `Unity.exe -batchmode -quit -projectPath UnityProject -executeMethod AlatauCity.EditorTools.AlatauBuild.BuildWindowsCI -logFile build.log`

## Что нужно от нас, когда будет доступ
1. Домен или поддомен (например `twin.qtwin.kz`) и доступ к DNS.
2. Решение: сервис (A1) или свой GPU-сервер (A2).
3. Для A2 — сервер с видеокартой NVIDIA и публичным IP.
