## 2. Как устроен код

`UnityProject/Assets/Scripts/DigitalTwin/`:
- `Modules/`: модули (Обзор, Стройка, Объекты и инвестпроекты, Инфраструктура, Прогноз, Ситуационный центр).
- `Landmarks/`: Iconic, KAIST, мониторинг стройки (Контроль, Дефекты, Смета, Документы, Съёмки, BIM 4D, Видео).
- `Layers/`: слои карты: дороги `FilmRoads`, трафик `FilmTraffic`, люди и флаги `FilmLife`, фонари `FilmLamps`, ЛРТ `LrtLayer`, ж/д `RailLayer`, солнечные `SolarLayer`.
- `UI/`: оболочка `TwinUI`, виджеты `Widgets` (`Details` = «ответ сверху, пояснения под «Подробнее»»), источники `SourceTags`.
- `Data/`: `Sources.cs` (реестр источников), `InvestRegistry.cs` (30 инвестпроектов из прессы), `TwinModels.cs`.
- Корень: `TwinTour.cs` (режим презентации), `TwinPitch*.cs` (питчи), `Loc.cs` + `UiTranslator` (языки RU/EN/KZ, строки в `Resources/Loc/strings.json`).

Данные: `Assets/Resources/Film/`, `Assets/Resources/Landmarks/*.bytes`, `Assets/StreamingAssets/twin/*.json`, `Assets/CityData/`. Шейдеры: `Assets/Shaders/` (`AlatauFilm.cginc`, `AlatauLit`, `AlatauRoad`, `AlatauCar`, `AlatauLandmark`).

Клавиши и меню в Unity:
- F4: навигатор режима презентации. F5: меню питчей, Shift+F5: питч инвестору, Ctrl+F5: питч госоргану.
- Меню `Alatau City/Build WebGL` собирает сайт в `UnityProject/Builds/alatau-webgl.zip`.
- Меню `Alatau City/Record film 60 s` записывает ролик.

`tools/`:
- `tools/map/`: генератор новой карты на Python (этап 7, раздел 5).
- `tools/claude/`: инструменты на Gemini: тестер, проверка кадров и дизайна, генератор картинок, переводы (`tools/claude/README.md`).
- `tools/webgl_check/`: проверка сайта в Chrome (`check_build_windows.ps1`). Проверке без видеокарты (SwiftShader) не верить, она всегда падает.
- `UnityProject/Tools/twin_gen`: старый генератор данных двойника.

## 5. Генератор карты (tools/map) на Windows

1. Python 3.12+ и пакеты: `pip install -r tools/map/requirements.txt`.
2. Данные: `python tools/map/inputs/join.py` склеит 4 части архива, сверит sha256 и распакует в `tools/map/inputs/stage7/`.
3. Переменные окружения (пути по умолчанию в коде облачные, `/mnt/...`):
   - `ALATAU_OUT` = `<репо>\tools\map\out`
   - `ALATAU_TWIN` = `<репо>\UnityProject\Assets`
   - `ALATAU_W34` = `<репо>\tools\map\inputs\stage7\level0\w34`
   - `ALATAU_MAKET` = `<репо>\tools\map\inputs\stage7\alatau_maket`
4. Жёсткие пути без переменной, заменить первым делом: `tools/map/export/util.py:19–20` (TWIN, OUT), `tools/map/export/ground.py:77` (PICTURE → `stage7/out/_fixtures/w48/ground_types.png`), `tools/map/district/growing_w_common.py:30` (W35_INFRA → `stage7/level0/w35/overture/infrastructure.parquet`). Тесты читают `stage7/out/_fixtures`.
5. Проверка: `python -m pytest tools/map/tests` (или по файлам), потом `python tools/map/run.py gate_trial`: должна быть 1 ошибка (правило 25, съезд s35).

Как устроено: `spec/<район>.json` + `spec/city.json` → `run.py <район>`: улицы (`gen/gen_network.py`), ЛРТ (`gen_lrt.py`), кварталы и участки (`gen_blocks_lots.py`), здания (`gen_buildings.py`), маски (`gen_masks.py`) → проверка по 25 правилам (`validate/validate_map.py`, отчёт `report.md`, `report.png`). Затем `export/merge_districts.py --run <имя>` собирает все районы и пишет файлы Unity в `<OUT>/_merged/<имя>/Assets`; `export/ground.py --nature-base stage7/integ/twin_base/map_nature.png` рисует землю; `export/check_merge.py` проверяет сборку. Договорённости между частями: `tools/map/CONTRACT.md`. Нормы: `spec/norms.json`, правила: `spec/rules.json`, реестр готовых объектов: `spec/registry.json`. Планы районов (картинки): `stage7/level0/schemes/*/scheme.md`.
