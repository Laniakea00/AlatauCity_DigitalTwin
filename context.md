# Alatau City — цифровой двойник города (qTwin)

Состояние на 7 октября 2026 года. Как открыть и собрать проект — в `startup.md`.

## 1. Что это

Демонстрационный цифровой двойник нового города **Alatau City** на платформе qTwin (QazTWIN). Город строится между Алматы и Конаевом, вдоль трассы Алматы–Конаев, у реки Каскелен и Капшагайского водохранилища.

- **Для кого:** показ государству и инвесторам.
- **Платформа:** Unity 6000.0.84f1 (Built-in Render Pipeline), Windows.
- **Устройство:** одна сцена, одна 3D-модель, одна шкала времени 2025–2050 и шесть модулей-вкладок.
- **Главный вопрос любого экрана:** «как это выглядит в году N при сценарии S».
- **Районы:** 4 — Gate, Golden, Growing, Green. Около 88 000 га, ≈1,87 млн жителей к 2050 году.
- **Застройка:** 57 690 зданий с годом ввода. Из них 13 445 существующих (OpenStreetMap), остальные — генплан и сценарий застройки QTwin.

**Все эксплуатационные, строительные, IoT- и финансовые данные синтетические**, но согласованы между собой и с генпланом (постановление Правительства РК № 388 от 17.05.2024). На экране всегда есть плашка «Демо-сценарий · данные смоделированы». Это не официальные данные.

## 3. Ключевые решения

| Решение | Почему |
|---|---|
| Без импорта FBX/OBJ: геометрия экспортируется из Blender в свои бинарники, меши строит Editor-скрипт | Импорт FBX давал битую геометрию и упирался в лимит 65k вершин. Сейчас 57k зданий лежат в 71 меше, без GameObject на каждое здание |
| Подложка — перерисованная карта генплана, без спутника | Требование заказчика: вид «аккуратного макета» |
| Всё состояние зданий (год, выделение, стройка, окраска) — в одном шейдере через глобальные параметры и текстуры-таблицы bid → значение | Смена года или сценария мгновенная, 60 fps на 57k зданий |
| UI — Unity UI Toolkit (USS), без IMGUI и uGUI | Стиль qTwin, адаптивность, свои графики на `Painter2D` |
| Синтетика — детерминированный Python-генератор (seed 2050) → JSON в `StreamingAssets` | Воспроизводимость, одна «правда» для всех модулей |
| Язык интерфейса — пока только RU. Словари EN/KZ в `Loc.cs` есть, но переключатель скрыт | Решение заказчика |
| ИИ — сценарное демо: ответы по ключевым словам, но все цифры считаются из данных двойника. Живого LLM и ключей API в сборке нет | Решение заказчика. Архитектура ответов повторяет вызовы инструментов (`set_year`, `fly_to`, `show_layer`, `run_scenario`, `query`), поэтому LLM можно подключить позже |
| Сборка — Windows. WebGL отложен | Решение заказчика |

## 4. Что сделано

### Оболочка платформы (стиль qTwin, редизайн 07.10)
- **Шапка:**
  - логотип qTwin;
  - место, погода и часы;
  - **выбор района** по центру (весь город / Gate / Golden / Growing / Green);
  - **сценарий**, **год**;
  - иконки: ИИ, уведомления (бейдж, если есть дефициты), презентация;
  - аватар «Демо-доступ · Главный архитектор».
- **Левая узкая панель иконок модулей.** Раскрывается кнопкой со стрелками, подсказки при наведении, внизу — запуск презентации.
- **Две колонки плавающих панелей**, слева и справа; центр свободен под карту. Заголовок любого блока сворачивает его кликом. Второстепенные блоки свёрнуты с самого начала.
- **Нижняя плавающая панель:** пуск и пауза таймлайна, шкала 2025–2050 с вехами, виды камеры (обзор, сверху, на север). Над ней — легенда текущего слоя.
- **Компактный режим** для экранов уже 1560 px (проверено на 1920×1080 и 1366×768).
- **Паспорт здания по клику:** район, тип, год, высота, этажи, GFA, участок, координаты UTM.
- **Дизайн-токены:**
  - фон `#0a0a0a`, панели `rgba(16,16,16,.94)`, текст `#fdfcfc` / `#c3c3c3` / `#878787`;
  - акцент qTwin — красный `#e0261b`;
  - статусы: ok `#34c759`, warn `#f5a623`, bad `#ff3b2f`;
  - выделенный объект `#d946ef`;
  - ИИ — фиолетовый `#a78bfa`.
- **Шрифт и иконки:** шрифт Geologica (OFL), иконки Lucide (ISC), растеризованы в PNG.

### Карта и «рост города» (редизайн 07.10)
- **Подложка:** `Tools/twin_gen/gen_map.py` распознаёт классы зонирования в исходной PNG генплана и рисует их спокойной палитрой с отмывкой рельефа. Шумные подписи старой карты убраны. Получаются три текстуры в `Assets/Resources/Map/`:
  - `map_plan.png` — город по генплану;
  - `map_nature.png` — та же земля до застройки: степь со слабым «призраком» плана;
  - `map_dev.png` — год освоения каждого места.
- **Шейдер `AlatauCity/Ground`** показывает землю по году: степь → земляные работы (≈2 года до ввода) → цвет генплана. Темп зависит от сценария (`_AlatauDevK`).
- **Рост при проигрывании таймлайна:** новые здания поднимаются по этажам и около года светятся тёплым цветом. Остальные здания приглушены, чтобы рост читался в контексте города (`AlatauLit`: `_AlatauGrow`, `_AlatauYearF`, `_AlatauBldSat`). Скорость — не быстрее 1 с на год.
- `MapStyle.cs` при запуске подменяет материал рельефа, скрывает старые подписи и перекрашивает линии (ЛРТ, оси улиц, реки, ж/д).

### Сценарии
- «Базовый (генплан)», «Ускоренный», «Отставание», «Приоритет инфраструктуры».
- Сценарий пересчитывает год ввода каждого здания (`TwinScenario.EffectiveYear`, формула совпадает с Python `twin_common.effective_year`) и передаёт его в шейдер таблицей 256×256 bid → год. Вслед за этим пересчитываются население, нагрузки, трафик, деньги и рост карты.

### M0 «Обзор»
- **Вывод одной фразой:** «В 2032 году в Alatau City живут 413 тыс. человек, город готов на 27 %».
- **Слева:**
  - шкала готовности;
  - 4 KPI: жители, введено м², рабочие места, зданий стоит;
  - районы строками «жители / цель 2050 · %»;
  - график роста по назначению.
- **Справа:**
  - «Журнал событий года»: начало дефицитов, отставание стройки, открытие очередей ЛРТ, ввод объектов сетей, сданные здания. Карточки с цветной полосой и бейджами Критично / Средний / Ввод;
  - «AI-аналитика»: первый дефицит электроэнергии, школы, транспорт; кнопка «Рекомендации» ведёт в модуль ИИ.
- **Клик по району** — перелёт камеры и панель района: назначение, площадь, население, KPI.

### M1 «Стройка»
- **3D:** здания растут по прогрессу стройки, со «строительными лесами». Цвета: оранжевый — по графику, красный — отстаёт, зелёный — сдан в этом году.
- **Слои линий:** 6 магистральных сетей (в прокладке — пунктир), дорожные работы, трафик v/c.
- **Панели:**
  - KPI;
  - S-кривая «план / факт»;
  - деньги по источникам: бюджет, частные, ГЧП, квазигосударственные;
  - сети и дороги в работе;
  - топ отстающих объектов (клик — перелёт и паспорт);
  - рейтинг генподрядчиков.
- **BIM-квартал Gate Q1:** 9 880 элементов IFC из набора QTwin.
  - График QTwin 2027 сдвинут на +4 года: квартал строится 03.2031–02.2032, как в сценарии города.
  - Слайдер дат с датами съёмок БПЛА.
  - Статусы элементов: смонтировано / в работе / отстаёт / не начато (полупрозрачный «призрак»).
  - Этапы «факт / план», охрана труда по видеоаналитике, карточка элемента с GUID.

### M2 «Прогноз»
- **Метрики:**
  - 5 сетей: электроэнергия, тепло, газ, вода, канализация;
  - школы, детсады, больницы;
  - транспорт;
  - землетрясение (8–9 баллов, уязвимость по типу и возрасту здания);
  - паводок (подъём 1,6 / 3,0 м).
- **Для каждой метрики:** вывод одной фразой, 4 KPI, график «спрос против мощности» по годам, строки районов, кнопка «Почему так?» с формулой и допущениями.
- **3D:** здания окрашены по результату района или по своему риску, земля приглушена.

### M3 «Инфраструктура»
- **Ресурсы:** ПС 220/110, электросети 10 кВ, тепло, газ, вода, канализация — строки «нагрузка / мощность», клик фокусирует слой.
- **Объекты:** пины объектов и станций ЛРТ над картой, карточка объекта, однолинейная схема электросети, ввод очередей на 3 года вперёд.

### M4 «Ситуационный центр»
- **Ускоренный день города:** 1 с = 8 мин. До 2030 года город почти пуст, поэтому модуль предлагает перейти в 2036.
- **Лента событий** из 6 типов источников: фильтры, «только важные», клик — перелёт к событию.
- **Источники данных:** 16 потоков с протоколом, частотой, числом точек и живым значением.
- **«Брифинг» для акима.**
- **8 сценариев решений:**
  - утечка на водоводе;
  - перегрузка ПС «Golden»;
  - ДТП на трассе;
  - паводок на Каскелене;
  - сдвиг ЛРТ;
  - облачность и СЭС;
  - пожар на складе;
  - срыв поставки бетона на Gate Q1.
- **Сравнение «решение принято / не принято»:**
  - ползунок времени;
  - таблица: люди, ущерб, восстановление, нагрузка на соседние сети, CO₂;
  - график ущерба;
  - переключатель веток на карте.

### M5 «ИИ-управление»
- **Ассистент:**
  - поле вопроса, 6 готовых вопросов и блок «С чего начать»;
  - ответ включает текст, факты, график, список «что сделал ИИ», уверенность в % и источники;
  - ИИ сам меняет год, двигает камеру, красит здания и ставит пины.
- **Автопилот:**
  - режимы «только советует» / «действует сам в пределах регламента»;
  - 3 аномалии;
  - 3 варианта с прогнозом, рекомендация и «почему», журнал действий, кнопка «Отменить»;
  - ограничение потребителей — только с подтверждением человека.
- **«Без ИИ / с ИИ» на утечке:** обнаружение 4,5 ч → 4 мин, изоляция 5 ч → 40 мин.
- **7 историй:** светофоры, ВИЭ + накопители, предиктивное обслуживание трансформатора, паводок за 30 ч, вывоз отходов, СИЗ по камерам, генеративный выбор места новой школы.

### Презентация (авто-тур)
- **Запуск:** кнопка в левой панели или F5. Пробел — пауза, ← → — шаги, Esc — выход. Код — `TwinTour.cs`.
- **16 шагов, около 6 минут:** город 2025 → рост до 2050 → сценарий «Отставание» → стройка 2033 → BIM Gate Q1 → сети → дефицит электроэнергии 2034 → школы → паводок → ситуационный центр → утечка «не принято / принято» → ИИ-ассистент → без ИИ / с ИИ → новая школа → город 2050.

### Сборка
- Windows x64, полноэкранное окно 1920×1080. Около 690 МБ: выросла из-за карты 8K.

## 5. Архитектура

```
Assets/CityData (геометрия из Blender) ──► Editor/AlatauCityBuilder ──► сцена + Assets/Generated (меши)
Assets/StreamingAssets/twin/*.json (синтетика) ──► Data/TwinData (загрузка в фоне) ──► модули и слои
TwinState (год, сценарий, модуль, район, выделение) ──события──► TwinUI, модули, слои, шейдеры
```

- **`TwinState`** — глобальное состояние с событиями.
- **`TwinUI`** — сам строит весь UI при загрузке сцены, UI-объектов в сцене нет.
- **Модули** реализуют `ITwinModule` (`BuildPanel(left, right)`, `Refresh`, вход и выход). Базовый класс — `TwinModuleBase`.
- **Слои** (`Layers/`):
  - `ConstructionLayer` — состояние стройки в текстурах для шейдера;
  - `TintLayer` — окраска зданий bid → цвет;
  - `LineLayers` — сети, дороги, трафик; ширина в пикселях экрана;
  - `MapPins` — пины над картой;
  - `BimQuarter` — квартал Gate Q1.
- **Глобальные параметры шейдеров:**
  - `_AlatauYear`, `_AlatauYearF` — год (дробный при проигрывании);
  - `_AlatauGrow` — режим роста;
  - `_AlatauScenario` + `_AlatauYearTex` — год ввода по сценарию;
  - `_AlatauMode`: 0 — обычный, 1 — стройка, 2 — анализ;
  - `_AlatauStateTex`, `_AlatauGeoTex`, `_AlatauTintTex` — таблицы состояния, геометрии и окраски;
  - `_AlatauSel` — выделенное здание;
  - `_AlatauDevK` — темп освоения земли;
  - `_AlatauBldSat` — насыщенность зданий.
- **Система координат:** X — восток, Y — высота над уровнем моря (м), Z — север. UTM 43N: E = 663000 + X, N = 4830000 + Z.

## 6. Данные

**Геометрия** (`Assets/CityData`, экспорт `Tools/blend_export.py` из `Alatau_City_3D.blend` набора QTwin):
- `terrain_heights.bytes` — рельеф, сетка 50 м, 873×1235;
- `layer_*.bytes` — здания, инфраструктура, подписи; свой формат AQL1;
- `buildings.csv` — 57 690 зданий;
- `city_meta.json` — палитра, камеры, параметры рельефа.

**Синтетика** (`Assets/StreamingAssets/twin`, ≈8 МБ):

| Файл | Содержимое |
|---|---|
| `roads.json` | Граф дорог, годы открытия по сценариям |
| `networks.json` | Объекты инфраструктуры (очереди, мощность) и магистральные сети вдоль улиц |
| `loads.json` | Жители, рабочие места, нагрузки и балансы по районам, социальная инфраструктура |
| `construction.json` | Длительность стройки по каждому зданию, генподрядчик, задержка; S-кривые; очереди ЛРТ |
| `finance.json` | CAPEX по годам, районам, назначению и источникам (млрд ₸, цены 2026) |
| `traffic.json` | Утренний час пик 2030–2050: загрузка рёбер и KPI |
| `risk.json` | Паводок: глубина по зданиям |
| `gate_q1.bytes`, `gate_q1.json` | BIM-квартал Gate Q1 |
| `scenarios.json` | Описание сценариев |

**Генераторы** — `Tools/twin_gen`, описание в `README.md` там же: `gen_twin.py`, `gen_roads.py`, `gen_risk.py`, `gen_map.py`, `bim_export.py`, `extract_blend.py`, `validate_twin.py`. Нормы и допущения с источниками — в `norms.py`.

**Сверка с открытыми данными:** 1,86 млн жителей и 1,04 млн рабочих мест к 2050 году (официально ~1,8 млн и ~1 млн). Инженерная инфраструктура 2026–2030 — 731 млрд ₸ (по открытым данным ≈678 млрд ₸).

**Заложенные «ошибки плана»** — их показывает двойник:
- 2-я очередь ПС 220/110 «Golden» сдвинута на +3 года: дефицит электроэнергии в Golden с 2034 года;
- 2-я очередь котельной «Growing-1» сдвинута на +3 года;
- 3-я очередь КОС № 4 сдвинута на +3 года: дефицит канализации около 2040–2041 года;
- школы: в целом по городу мест хватает, но в Growing обеспеченность низкая.

Реальные, но неподтверждённые названия (например, «ПС Арна») не используются: модельные объекты названы по районам.

## 7. Ограничения и что дальше
- WebGL-сборка (ссылка в браузере) — не сделана, отложена заказчиком. Нужно будет ужать текстуры: карта 8K весит много.
- Языки EN/KZ: словари частично есть в `Loc.cs`, тексты модулей M4/M5 и тура пока только на русском.
- ИИ — сценарный. Для живой LLM ответы нужно перевести на вызовы инструментов (`set_year`, `fly_to`, `show_layer`, `run_scenario`, `query`) — они уже выделены в коде `AiModule.cs`.
- Не сделаны идеи из раздела 6 ТЗ: инвестиционная карта, вид для жителя, ESG, цифровые разрешения, экспорт PDF.
- Ситуационный центр показывает один синтетический «день» на выбранный год, а не поток в реальном времени.
- Исходный blend-файл QTwin (`Alatau_City_3D.blend`) в архив не входит. Он нужен только для повторного экспорта геометрии; всё, что нужно для работы, уже лежит в `Assets/CityData`.
